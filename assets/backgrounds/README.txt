BACKGROUND IMAGES FOLDER
========================

Place your background images here. 

Supported formats: .jpg, .jpeg, .png, .webp

The landing page will automatically cycle through all images in this folder.

Recommended:
- Use landscape orientation images
- Aim for 1920x1080 or higher resolution
- Keep file sizes reasonable (under 2MB each for faster loading)

Example filenames:
- photo1.jpg
- photo2.jpg
- sunset.png
- mountains.webp
